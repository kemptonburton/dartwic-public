Settings control interface and environment behavior. Use settings when the question is about how the workspace behaves, not about the live value of a channel.

# Common Settings Areas

- interface preferences
- project or runtime connection options
- plugin settings
- resource behavior
- display and interaction preferences
- environment-specific options

# Operator Guidance

- change settings intentionally and document deployment-specific defaults
- prefer plugin-provided settings for plugin behavior
- use module configuration pages for engine module instance parameters
- do not use settings as a substitute for live command channels or task controls
