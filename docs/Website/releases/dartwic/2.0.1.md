## Overview

Patch release for DCode event and calculation correctness, clearer editor documentation, and more reliable local-engine setup and portable state in the Desktop and Webserver Interfaces. Public guides and generated references now explain maintained triggers, pulse timing, and calculation fallback accurately.

## DARTWIC Engine Changes

- Preserve event-owned firing and board state when extra reaction dependencies change.
- Fix Lua activation of unconditional event trigger returns.
- On target calculation failure or a missing numeric result, use the original submitted value, discard partial transformations, skip remaining target calculations, and report an ARGUS warning with source, target, writer, and fallback context.

## Desktop Interface Changes

- Show complete DCode signatures, lifecycle, and persistence guidance in editor hovers and completions.
- Keep portable interface state and local-engine registrations beside the installation and preserve them during updates.
- Improve engine download/adoption and workspace selection in Interface settings and Add Workspace.

## Webserver Interface Changes

- Include corrected DCode editor guidance for maintained events, pulses, and calculation behavior.
- Use installation-local engine registration and preserve .dartwic state across updates.
- Align local-engine download and workspace setup with the Desktop Interface.

## Upgrade notes

Use the full Desktop or Webserver package for these host changes; a UI-only update is not sufficient. Minimum compatible Engine remains 2.0.0. Calculation fallback still applies normal RAPID numeric conversion and authority checks, and does not roll back calculation side effects. Windows regression checks passed; Linux packages are built through GitHub Actions.
