# Public website documentation

Everything in this directory, including guides, generated references, release notes, and attachments, is public. Write for readers using published DARTWIC packages and documentation.

- Use only published SDKs, clients, APIs, headers, and examples in code snippets and setup instructions. For C++ plugin examples, check the public [Engine Plugin SDK](../../sdk/engine_plugin_sdk/README.md) and its shipped headers.
- Keep closed-source headers, classes, functions, source paths, private repository links, and internal-only tooling out of public content. Explain user-visible behavior in terms of public features and APIs.
- Verify examples against the shipped public dependencies. If a capability is internal, document the supported public workflow or leave the internal API out.
