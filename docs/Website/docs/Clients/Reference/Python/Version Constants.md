---
title: "Version Constants"
summary: "Package and engine compatibility versions exported by the Python client."
---

| Constant | Value | Description |
| --- | --- | --- |
| `__version__` | `"2.0.0"` | Installed DARTWIC Python client version. |
| `MIN_ENGINE_VERSION` | `"2.0.0"` | Oldest DARTWIC engine version supported by this client. |
