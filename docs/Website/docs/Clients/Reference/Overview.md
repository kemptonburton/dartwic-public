## Client libraries

| Library | Description |
| --- | --- |
| [Python](Python/Overview.md) | Python client APIs for operations and RAPID channel queries. |
| [Node.js](Node.js/Overview.md) | Asynchronous operations, channel subscriptions and exact recorded timestamps. |
| [C++](C++/Overview.md) | Native operations, channel subscriptions and recorded history. |
| [React](React/Overview.md) | React context and hooks for connections and live RAPID channel data. |
| [TEMPEST Peer](TEMPEST/Overview.md) | Generic peer operations, telemetry and optional ZeroMQ transport. |
