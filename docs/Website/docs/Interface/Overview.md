The Interface is where you watch a system, operate it, and review what happened. Open resources from the sidebar and arrange them in tabs or panels to suit your work.

For installation and your first connection, follow [First Session](../Getting%20Started/First%20Session.md).

# Find the right page

| You want to… | Read… |
| --- | --- |
| Find a signal or change a value | [Channels](Channels.md) |
| Investigate a condition or answer a prompt | [Events](Events.md) |
| Read startup, device, or script output | [Logs](Logs.md) |
| Plot signals and compare a time range | [Telemetry Graphs](Telemetry%20Graphs.md) |
| Save a run, browse recordings, or download data | [DataFrames, Databases, and Exporting Data](DataFrames%2C%20Databases%2C%20and%20Exporting%20Data.md) |
| Configure a device or run automation | [Modules and Tasks](Modules%20and%20Tasks.md) |
| Inspect clients and remote connections | [Network Map](Network%20Map.md) |
| Edit and activate a script | [DCode Editor](DCode%20Editor.md) |
| Build a reusable operator display | [Schematics](Schematics.md) |
| Inspect a selection or review project changes | [Node, Context, and Project Board](Node%2C%20Context%2C%20and%20Project%20Board.md) |
| Find navigation and configuration controls | [Navbar, Sidebar, and Settings](Navbar%2C%20Sidebar%2C%20and%20Settings.md) |
| Add drivers or Interface tools | [Plugins](Plugins.md) |

For the behavior behind these views, see the [Engine guides](../Engine/Overview.md).
