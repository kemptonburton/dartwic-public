The Interface is the application you use to configure and operate a system, watch live signals, and review recorded runs. It connects to an **Engine**, the process that communicates with equipment, runs automation, and records data. For installation and your first connection, follow [First Session](../Getting%20Started/First%20Session.md).

![Recorded measurements, events, and logs reviewed together in the Interface.](../Engine/_attachments/Pasted%20image%2020261029010151.png)

Check the node and project at the top left, then open views from the sidebar. The guides below focus on using those views; the [Engine guides](../Engine/Overview.md) explain how their underlying features work. Screenshots use example projects, so resource names and available plugins will vary.
