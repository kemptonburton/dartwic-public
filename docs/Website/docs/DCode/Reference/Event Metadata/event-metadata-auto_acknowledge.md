---
title: auto_acknowledge
summary: Non-negative seconds before ARGUS automatically acknowledges the event. Zero disables it.
created: 2026-10-04T18:31
updated: 2026-10-22T17:41
---

## Syntax

```dcode
auto_acknowledge: <seconds>
```

## Available in

- An event declaration

## Example

```dcode
auto_acknowledge: 0
```
