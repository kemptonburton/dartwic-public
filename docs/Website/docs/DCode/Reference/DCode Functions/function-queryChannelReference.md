---
title: "queryChannelReference"
summary: "Query a typed channel reference."
---

## Syntax

```dcode
queryChannelReference(reference)
```

## Available in

- File scope
- Executable DCode bodies

## Native C++

Native C++ calls this function through the engine host. It can allocate or block; review use in a control callback.

## Example

```lua
queryChannelReference(channel_reference)
```
