---

## Syntax

```dcode
pcall(function_name, ...)
```

## Available in

- File scope
- Executable DCode bodies

## Native C++

Lua only. This feature has no Native C++ code-generation binding.

## Example

```dcode
pcall(function_name, arg)
```
