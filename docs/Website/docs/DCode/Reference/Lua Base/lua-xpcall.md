## Syntax

```dcode
xpcall(function_name, error_handler)
```

## Available in

- File scope
- Executable DCode bodies

## Native C++

Lua only. This feature has no Native C++ code-generation binding.

## Example

```dcode
xpcall(function_name, error_handler)
```
