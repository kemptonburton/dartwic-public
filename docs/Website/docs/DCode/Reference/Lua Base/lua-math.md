## Syntax

```dcode
math.<member>
```

## Available in

- File scope
- Executable DCode bodies

## Native C++

Native bindings: abs, acos, asin, atan (one or two arguments), ceil, cos, deg, exp, floor, fmod, log (optional base), max, min, pow, rad, sin, sqrt, tan; constants pi and huge. Other math members are unavailable.

## Example

```dcode
math.
```
