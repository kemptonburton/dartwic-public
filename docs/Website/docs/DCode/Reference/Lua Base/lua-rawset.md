---
title: "rawset"
summary: "Write a table field without metamethods."
---

## Syntax

```dcode
rawset(table_value, key, value)
```

## Available in

- File scope
- Executable DCode bodies

## Native C++

Lua only. This feature has no Native C++ code-generation binding.

## Example

```lua
rawset(table_value, key, value)
```
