---
title: "type"
summary: "Return the DCode value kind: number, string, boolean, array, object, or null for shared DCode values in both backends."
---

## Syntax

```dcode
type(value)
```

## Available in

- File scope
- Executable DCode bodies

## Native C++

Returns DCode value kinds, including array, object and null, in both backends.

## Example

```dcode
type(value)
```
