---
title: "Plugins"
summary: "Inspect installed plugins and the capabilities they register."
---

| Operation | Description |
| --- | --- |
| [`dartwic/plugins/install-engine-plugin`](dartwic/plugins/install-engine-plugin.md) | Installs an Engine plugin package's files without loading native code into the running Engine. A replacement is staged for restart. |
| [`dartwic/plugins/install-engine-plugin/start`](dartwic/plugins/install-engine-plugin/start.md) | Starts a detached engine plugin installation job. |
| [`dartwic/plugins/list-installed-engine-plugin-groups`](dartwic/plugins/list-installed-engine-plugin-groups.md) | Reads installed Engine plugin files and the current Engine's loaded-plugin registry separately. |
| [`dartwic/plugins/list-installed-engine-plugins`](dartwic/plugins/list-installed-engine-plugins.md) | Lists installed engine plugins. |
| [`dartwic/plugins/read-module-icon`](dartwic/plugins/read-module-icon.md) | Reads an installed plugin module icon as a data URL. |
| [`dartwic/plugins/uninstall-engine-plugin`](dartwic/plugins/uninstall-engine-plugin.md) | Queues removal of an Engine plugin package. Installed files and loaded code remain until restart. |
| [`dartwic/plugins/uninstall-engine-plugin/start`](dartwic/plugins/uninstall-engine-plugin/start.md) | Starts a detached engine plugin removal job. |
