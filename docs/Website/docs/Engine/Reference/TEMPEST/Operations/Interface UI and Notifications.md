---
title: "Interface UI and Notifications"
summary: "Official TEMPEST operations in the Interface UI and Notifications category."
---

| Operation | Description |
| --- | --- |
| [`dartwic/interface-ui/complete-request`](dartwic/interface-ui/complete-request.md) | Completes, dismisses, or cancels an interface UI request. |
| [`dartwic/interface-ui/get-request`](dartwic/interface-ui/get-request.md) | Returns one interface UI request, including its completion result. |
| [`dartwic/interface-ui/get-requests`](dartwic/interface-ui/get-requests.md) | Lists interface UI requests, optionally filtered by UI ID and status. |
| [`dartwic/interface-ui/set-request-muted`](dartwic/interface-ui/set-request-muted.md) | Changes an engine-scoped mute associated with one pending interface UI request. |
| [`dartwic/notifications/get-muted`](dartwic/notifications/get-muted.md) | Lists persistent global and active-project notification mute choices from the workspace. |
| [`dartwic/notifications/set-muted`](dartwic/notifications/set-muted.md) | Changes one workspace notification mute choice by its stable identity. |
