---
title: "TEMPEST peers"
summary: "Exchange selected runtime data through TEMPEST peers workflows."
---

| Operation | Description |
| --- | --- |
| [`tempest/peers/connect`](tempest/peers/connect.md) | Connects the engine to a TEMPEST peer. |
| [`tempest/peers/definitions`](tempest/peers/definitions.md) | Lists built-in and plugin-provided peer definitions. |
| [`tempest/peers/disconnect`](tempest/peers/disconnect.md) | Disconnects a TEMPEST peers node. |
| [`tempest/peers/get-runtime-metadata`](tempest/peers/get-runtime-metadata.md) | Returns runtime metadata. |
| [`tempest/peers/list`](tempest/peers/list.md) | Lists configured and connected TEMPEST peers nodes. |
| [`tempest/peers/operations`](tempest/peers/operations.md) | Lists the selected node's currently callable operations, including the current engine. |
| [`tempest/peers/presets/list`](tempest/peers/presets/list.md) | Lists shared command presets for one stable peer identity. |
| [`tempest/peers/presets/run`](tempest/peers/presets/run.md) | Calls a saved pinned operation on the current engine or a connected peer. Overrides merge with saved arguments. |
| [`tempest/peers/presets/update`](tempest/peers/presets/update.md) | Atomically creates, edits, or removes one shared command preset. |
| [`tempest/peers/rapid/get-channel`](tempest/peers/rapid/get-channel.md) | Returns a channel from a remote RAPID runtime. |
| [`tempest/peers/rapid/list-channels`](tempest/peers/rapid/list-channels.md) | Lists channels exposed by a remote RAPID runtime. |
| [`tempest/peers/rapid/upsert-channel-field`](tempest/peers/rapid/upsert-channel-field.md) | Creates or updates a channel field on a remote RAPID runtime. |
| [`tempest/peers/reconnect-remembered`](tempest/peers/reconnect-remembered.md) | Reconnects a previously remembered TEMPEST peers node. |
| [`tempest/peers/telemetry`](tempest/peers/telemetry.md) | Lists telemetry topics registered by a connected peer. |
