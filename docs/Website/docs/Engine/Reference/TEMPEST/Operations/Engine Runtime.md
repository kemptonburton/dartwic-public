| Operation | Description |
| --- | --- |
| [`dartwic/engine/get-config`](dartwic/engine/get-config.md) | Reads running and saved engine settings without exposing credential values. |
| [`dartwic/engine/restart`](dartwic/engine/restart.md) | Requests an engine restart. |
| [`dartwic/engine/save-config`](dartwic/engine/save-config.md) | Saves administrator settings for the next restart. Node identity stays in workspace.json. |
| [`dartwic/engine/shutdown`](dartwic/engine/shutdown.md) | Requests a graceful engine shutdown without restarting it. |
| [`dartwic/get-runtime-metadata`](dartwic/get-runtime-metadata.md) | Returns runtime metadata. |
