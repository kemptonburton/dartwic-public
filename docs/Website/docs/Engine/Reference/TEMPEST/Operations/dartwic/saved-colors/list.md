title: "dartwic/saved-colors/list"
summary: "Lists the Engine instance's named palette across workspaces."
---

- **Category:** Projects and Files

## Request payload

This operation accepts an empty payload (`{}`).

## Response payload

| Field | Type | Description |
| --- | --- | --- |
| `colors` | `array<object>` | Saved entries with a name and light and dark hex values. A new palette is empty. |
