## SDKs

| SDK | Description |
| --- | --- |
| [Engine](Engine/Overview.md) | C++ APIs for engine plugins, modules, tasks, channels, DCode, operations, and events. |
| [Interface](Interface/Overview.md) | TypeScript APIs for interface plugins, configuration, resources, schematics, hooks, and UI components. |
| [TEMPEST](TEMPEST/Overview.md) | C++ messaging, custom transports, optional ZeroMQ and DARTWIC EngineProtocol. |
