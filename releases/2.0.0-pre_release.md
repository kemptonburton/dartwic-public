# Summary

2.0 is the next large update to DARTWIC ecosystem. While 1.0 was focused on building DARTWIC to be more reliable and user friendly for a single node, 2.0 focuses on expanding DARWIC to be scalable, multi-node capable, and more performant. 

2.0 focuses on building the tools to create a full ground vehicle system. This includes RTOS support for CAESAR with more accurate loop timing, RAPID determinism option, TEMPEST node to node communication (RAPID sharing), and a DARTWIC Code C++ Compiler. 

Other improvements have been made to places that needed it in 1.0, such as the alarming system, has been improved to become an entirely new observability and recording system called ARGUS.

# Planned Features

- Engine Driver
	- Deterministic RAPID
	- DCode C++ Compiler
	- Stripped down version of Engine
- Node to Node Communications
	- RAPID Sharing
	- Other data sharing (ARGUS, tasks, etc)
- CAESAR Improvements
	- State Machine Task
	- More accurate loop timing
- Engine Plugin Updates
	- DCode C++ binding.
- ARGUS
- Engine Linux support
- Smaller Features
	- Schematic node inspection
	- Channel not found/ telemetered notices (purple)

# Upgrade Notes

- Upgrading from 1.0 to 2.0
	- The only major incompatibility is that the engine plugin adds new DCode bindings and State Machine task structure. So any new plugins that use those need to have minimum engine version of 2.0.0
